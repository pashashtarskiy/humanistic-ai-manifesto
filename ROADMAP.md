# Roadmap / Дорожная карта

Author: Pasha Shtarskiy. Developed with Eli (ChatGPT).

| Version | Focus | Deliverables |
|---|---|---|
| 0.1.0 | Foundations / Основы | Three laws, six philosophical notes, preliminary literature map |
| 0.2.0 | Psychology / Психология | Define constructs, testable hypotheses, alternative explanations |
| 0.3.0 | Ethics / Этика | Privacy, manipulation, autonomy, conflicts of principles, shared responsibility |
| 0.4.0 | Implementation / Реализация | Practical design recommendations and evaluation criteria |
| 0.5.0 | Research / Исследования | Proposed study protocols, ethics review, preregistration and adverse-outcome measurement |
| 1.0.0 | Manifesto / Манифест | Integrated revision following critical review |

Versions are proposed milestones, not promises of empirical validation or dates. The project welcomes criticism and revisions.

## Motto / Девиз

Freedom without fear. Trust without submission. Progress without coercion.

Свобода без страха. Доверие без подчинения. Прогресс без принуждения.
